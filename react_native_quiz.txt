### Challenge Question

What is the bug in this code and how would you fix it?

```jsx
const [count, setCount] = useState(0);

const increment = () => {
  setCount(count + 1);
  setCount(count + 1);
};

<Button title="Add" onPress={increment} />
```

Explain:

1. What value `count` becomes after one click.
2. Why React behaves this way.
3. How to correctly increment twice.

# Firestore Lessons: Display, Update, and Delete Data

This lesson teaches how to:

1. Display existing data from Firestore
2. Update existing documents
3. Delete documents


# 3. Display Existing Data from Firestore

To display data, we use:

```javascript
getDocs()
```

---

# Example: Fetch All Students

```javascript
import { collection, getDocs } from "firebase/firestore";
import { db } from "./firebase";

async function getStudents() {
  const querySnapshot = await getDocs(collection(db, "students"));

  querySnapshot.forEach((doc) => {
    console.log(doc.id, "=>", doc.data());
  });
}

getStudents();
```

---

# Explanation

## `collection(db, "students")`

Accesses the `students` collection.

---

## `getDocs()`

Fetches all documents.

---

## `querySnapshot.forEach()`

Loops through documents.

---

## `doc.data()`

Returns document fields.

---

# Example Output

```text
student1 => {name: "John", age: 20}
student2 => {name: "Sarah", age: 22}
```

---

# 4. Update Existing Data in Firestore

To update a document, use:

```javascript
updateDoc()
```

---

# Example: Update Student Age

```javascript
import { doc, updateDoc } from "firebase/firestore";
import { db } from "./firebase";

async function updateStudent() {
  const studentRef = doc(db, "students", "student1");

  await updateDoc(studentRef, {
    age: 25,
  });

  console.log("Document updated");
}

updateStudent();
```

---

# Explanation

## `doc(db, "students", "student1")`

References a specific document.

---

## `updateDoc()`

Updates only specified fields.

---

# Before Update

```json
{
  "name": "John",
  "age": 20
}
```

# After Update

```json
{
  "name": "John",
  "age": 25
}
```

---

# Update Multiple Fields

```javascript
await updateDoc(studentRef, {
  name: "Johnny",
  age: 26,
});
```

---

# Important Note

`updateDoc()` only updates existing documents.

If the document does not exist:

```text
Error: No document to update
```

---

# 5. Delete an Existing Document

To delete a document:

```javascript
deleteDoc()
```

---

# Example: Delete Student

```javascript
import { doc, deleteDoc } from "firebase/firestore";
import { db } from "./firebase";

async function deleteStudent() {
  await deleteDoc(doc(db, "students", "student1"));

  console.log("Document deleted");
}

deleteStudent();
```

---

# Explanation

## `deleteDoc()`

Deletes the specified document permanently.

---

# Before Delete

```text
students
   ├── student1
   ├── student2
```

# After Delete

```text
students
   ├── student2
```

---

# 6. Complete CRUD Flow Example

CRUD means:

| Operation | Meaning      |
| --------- | ------------ |
| Create    | Add data     |
| Read      | Display data |
| Update    | Edit data    |
| Delete    | Remove data  |

---

# Full Example

```javascript
import {
  collection,
  getDocs,
  updateDoc,
  deleteDoc,
  doc,
} from "firebase/firestore";

import { db } from "./firebase";

// DISPLAY
async function displayStudents() {
  const snapshot = await getDocs(collection(db, "students"));

  snapshot.forEach((docItem) => {
    console.log(docItem.id, docItem.data());
  });
}

// UPDATE
async function updateStudent() {
  const ref = doc(db, "students", "student1");

  await updateDoc(ref, {
    age: 30,
  });
}

// DELETE
async function deleteStudent() {
  const ref = doc(db, "students", "student1");

  await deleteDoc(ref);
}
```

# 7. Real-Time Updates (Advanced)

Firestore can update automatically in real time.

Use:

```javascript
onSnapshot()
```

---

# Example

```javascript
import { collection, onSnapshot } from "firebase/firestore";

const unsub = onSnapshot(collection(db, "students"), (snapshot) => {
  snapshot.forEach((doc) => {
    console.log(doc.data());
  });
});
```

Whenever data changes, the UI updates automatically.

# 8. Common Errors and Solutions

| Error                    | Cause                        | Solution              |
| ------------------------ | ---------------------------- | --------------------- |
| No document to update    | Document doesn't exist       | Create document first |
| Missing permissions      | Firestore rules block access | Update rules          |
| Firebase not initialized | Wrong config                 | Check firebaseConfig  |
